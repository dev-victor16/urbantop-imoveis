## ✨ Principais Recursos do Novo Site

- **Identidade Visual Arquitetônica**: Cores autênticas *Urban Gold* (`#E5B32A`) combinadas a fundos nobres em grafite escuro (`#0B0D12`) e seções em off-white.
- **Hero Interativo**: Headline com proposta de valor clara, credenciais em tempo real e buscador inteligente integrado (Comprar / Alugar / Código / Região).
- **Métricas Animadas**: Contadores de tradição (+14 anos, CRECI 4298, +1.200 famílias, 6+ cidades da RMBH).
- **Vitrine Dinâmica de Imóveis**: Filtros instantâneos por abas (*Todos*, *Venda*, *Locação*, *Destaques*), cards com fotos reais de alta qualidade, especificações completas (quartos, vagas, banheiros, m²).
- **Modal de Detalhes do Imóvel**: Pop-up interativo com ficha técnica, descrição e botão direto para o WhatsApp pré-configurado com os dados exatos do imóvel.
- **Seção Habitacional Especial**: Guia explicativo sobre financiamento Caixa, Minha Casa Minha Vida, subsídios governamentais e uso do FGTS.
- **Presença Regional na RMBH**: Destaques de atuação em Ibirité, Contagem, Betim, Belo Horizonte, Sarzedo e Mateus Leme.
- **Canal do Proprietário**: Formulário simplificado para anúncio e avaliação de imóveis.
- **100% Responsivo**: Otimizado para Mobile (com menu Drawer tátil), Tablet e Telas Ultra-wide.
- **SEO Completo & Schema.org**: Marcação estruturada para motores de busca como `RealEstateAgent` e `LocalBusiness`.

## 🚀 Como Visualizar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador web, ou servir com um servidor local:

```bash
# Servir com Node.js
npx serve .
```
Acesse `http://localhost:3000`.
